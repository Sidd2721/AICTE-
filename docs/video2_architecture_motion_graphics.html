Modular API Domain Segregation

APIs are partitioned strictly by operational bounded contexts with explicit RBAC scopes:

  • /api/v1/instruments FDR submission, claim & lifecycle
  • /api/v1/deposits Regulatory norms & shortfall calculation
  • /api/v1/bank-portal Branch verification & tripartite signoff
  • /api/v1/release Maker-checker approval & DSC discharge
  • /api/v1/audit Cryptographic Merkle log verification
Server-Driven Workflow: Primary buttons in the React UI are directly computed by backend next_action(). No security logic lives on the client.
